# Provenance — the public RECALL demo

## Data

- **Synthetic only.** The meeting, speakers, transcript, decisions, actions, questions, evidence,
  redactions, field note, PPMA memory, pilot metrics, billing and admin data are generated by
  `scripts/build_demo_pack.py` with the fixed seed `20261030`.
- **No customer data.** No customer audio, transcript, personal data, phone number or client record is
  included.
- **No audio.** The waveform and player are a visualisation of the transcript timeline. The public build
  does not open the microphone.
- **Deterministic.** The generator contains no clock-dependent output; the same script produces the same
  `web/public/demo-pack.json`. CI regenerates it and fails on a diff.

## Reproducibility

```bash
py scripts/build_demo_pack.py       # or python3
cd web && npm ci && npm test && npm run build
```

Pack version `0.9.0`, anchor `2026-10-30T09:00:00Z`, seed `20261030`.

## Data rights

- Consent is recorded before capture in the demo flow. No event is emitted without a granted consent
  state.
- Raw media is not uploaded by default. PPMA receives derived text and a pointer.
- Redaction is a first-class object; the safe version is what leaves the device.
- Deletion leaves a tombstone; a replay cannot resurrect the content.
- No training on customer audio or transcripts — ever, without separate explicit consent.
- The demo's `localStorage` state is cleared by the Reset control in the transport bar or Settings.

## Public-demo boundary

The website is a product demo, not a pilot deployment. It uses a deterministic pack, a local PPMA fake
and reference metrics. The production swap points are named in
[`architecture.md`](architecture.md) and the roadmap's implementation note.
